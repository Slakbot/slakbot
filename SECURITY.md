# Security

If you find a security problem in SlakBot, please report it privately.

**Do not open a public issue for it.** A public report tells everyone how to use the problem before it is fixed.

## How to report

Use GitHub's private reporting: **[Report a vulnerability](https://github.com/Slakbot/slakbot/security/advisories/new)**.

If that does not work for you, send a direct message on [Discord](https://discord.gg/d9cpruNpyX) and ask for a private channel. Do not describe the problem in a public channel.

## What to include

- What you found, and what someone could do with it
- The steps to reproduce it
- Which part it affects: the bot, the dashboard, or the overlays

## What to expect

You will get a reply within a few days. Please give us a reasonable amount of time to fix it before telling anyone else.

SlakBot is run by one person, so thank you for reporting it instead of using it.
