# SlakBot

An all-in-one Discord bot: stream alerts, moderation, tickets, levels and an economy — set up from a web dashboard instead of chat commands.

**[Add SlakBot to your server](https://discord.com/oauth2/authorize?client_id=1473769439651696771&scope=bot+applications.commands&permissions=1101931080774)** · [Dashboard](https://panel.slakbot.nl/dashboard) · [Commands](https://slakbot.nl/commands) · [Status](https://slakbot.nl/status)

## What it does

- **Stream alerts** — YouTube, Twitch, TikTok LIVE and Twitch clips
- **Moderation** — warns, mutes, bans, word filter, anti-scam link and image scanning
- **AI moderation** — checks messages for toxicity, per channel
- **Tickets** — support channels, with a transcript when they close
- **Levels and economy** — XP, rank roles, daily rewards
- **Welcome messages** — with auto-role
- **Twitch chatbot** — shared economy between Discord and Twitch
- **OBS overlays** — alerts, chat and counters for streamers

The full list is at [slakbot.nl/commands](https://slakbot.nl/commands).
